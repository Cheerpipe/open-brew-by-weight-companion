Set up each device once

Each phone, tablet or computer needs to trust this gateway's certificate one time. Pick your device and follow the steps.

The certificate only works for @HOSTNAME@; it cannot be used to impersonate any other website.

iPhone and iPad
  1. Open this page in Safari and tap Download the profile. Choose Allow.
  2. Open Settings, tap Profile Downloaded near the top and then Install.
  3. Go to Settings → General → About → Certificate Trust Settings and switch on Open Brew by Weight local CA.
  4. Open @SECURE_URL@ and add it to your Home Screen if you like.
Mac
  1. Download the certificate and double-click it. Keychain Access opens; add it to the login keychain.
  2. In Keychain Access, double-click Open Brew by Weight local CA, open Trust and set When using this certificate to Always Trust. Close the window and confirm with your password.
  3. Restart your browser and open @SECURE_URL@.
Windows
  1. Download the certificate and open it.
  2. Choose Install Certificate…, then Current User.
  3. Pick Place all certificates in the following store, choose Browse… and select Trusted Root Certification Authorities. Finish and answer Yes to the security warning.
  4. Restart your browser and open @SECURE_URL@.
Android
  1. Download the certificate in Chrome.
  2. Open Settings and search for CA certificate. Usually it is under Security → More security settings → Encryption & credentials → Install a certificate → CA certificate.
  3. Tap Install anyway and pick the downloaded file. Android may ask you to set a screen lock first.
  4. Open @SECURE_URL@ in Chrome. Android 12 or newer is needed to open .local addresses.

Firefox keeps its own list of certificates on some systems. If it still shows a warning, import the certificate under Settings → Privacy & Security → View Certificates → Authorities and trust it for websites.
